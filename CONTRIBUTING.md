# Contributing to Kea

> [!NOTE]
> **About AI usage for contribution**
>
> We allow AI tools when they assist your work, but not when an AI generates everything with little to no effort on your part *("vibecoding")*. 
>
> Your contributions **must be mostly human-written**!
> We will not accept pull requests from fully autonomous AI agents acting on their own. (e.g. AI agent makes PR itself, not a human)

Kea is an open project for everyone to do anything they want!

## How can I contribute?
Contributions can be submitted via pull requests. You need to use Git
